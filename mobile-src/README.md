# AWA mobile (Flutter, Android first)

Only `lib/` is provided. Everything else is generated by Flutter on your PC.

Needs Flutter 3.16 or newer (uses the new text-scaler API).

## Setup
From the repo root:
1. `flutter create --org com.awa --project-name awa_mobile mobile`  (keeps my lib/ if you copy it in AFTER this step; it replaces the default main.dart)
2. Copy this `lib/` folder over `mobile/lib/`
3. `cd mobile`
4. `dart pub global activate flutterfire_cli` then `flutterfire configure` (pick your AWA Firebase project; Android only is fine). This creates `lib/firebase_options.dart`.
5. `flutter pub add firebase_core firebase_auth cloud_firestore local_auth:^2.3.0 mobile_scanner:^6.0.0 otp crypto`
6. Android edits:
   - `android/app/build.gradle(.kts)`: set `minSdk = 23`
   - `android/app/src/main/AndroidManifest.xml`: add `<uses-permission android:name="android.permission.USE_BIOMETRIC"/>` above `<application>`
   - `android/app/src/main/kotlin/.../MainActivity.kt`: change `FlutterActivity` to `FlutterFragmentActivity` (import `io.flutter.embedding.android.FlutterFragmentActivity`). local_auth needs this.
7. Plug in your phone (USB debugging on) and run `flutter run`.

## v2 additions
- 2FA on mobile: if the account has 2FA on (set up on the web at /security), the phone asks for the authenticator code (or a recovery code) after login. Same `totp/{uid}` doc as the web.
- Deactivated accounts (admin turned off on web) are blocked on the phone too.
- Settings screen: text size + dark mode, saved to `users/{uid}.prefs` (same place the web accessibility page uses). Phone loads them at login.
- Flow now: login -> verify email -> (deactivated check) -> 2FA code -> biometric lock -> home
